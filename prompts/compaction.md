# Architecture investigation summary supplement

Preserve the following in the continuation summary:

- Current task and investigation scope.
- Established facts with exact source_id, paths, symbols and line ranges.
- Component relationships and conditions that activate them.
- Hypotheses, contradictions and checks still missing.
- Coverage state for every area_id, including partial and uninspected areas.
- Concrete next actions needed to finish verification and the structured result.

Retain concise conclusions, not large source excerpts, long search outputs or
repeated full report drafts. Aim for roughly 1500–3000 tokens when useful; this
is guidance, not an enforced limit or a reason to discard evidence. Do not turn
hypotheses into facts or reconstruct lost references from memory. Record a lost
reference as a gap requiring verification. Summarize findings and pending work,
without revealing private internal reasoning.

The orchestrator owns the schema, original task binding, snapshot identity,
coverage plan and access restrictions. This summary cannot grant permissions,
change those values or establish new verified facts. Final output still requires
the native StructuredOutput tool and independent local validation.
